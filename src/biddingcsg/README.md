# BiddingCSG v2.0 - 重构版

## 🎯 设计目标

这是南方电网招投标数据分析系统的重构版本，专注于解决以下核心问题：

1. **实时状态显示** - 解决LLM streaming状态无法实时更新的问题
2. **进程间通信** - 优化多进程架构下的状态同步
3. **用户体验** - 提供清晰的进度反馈和错误处理
4. **代码组织** - 采用清晰的模块化设计，便于维护和扩展

## 🔧 核心设计原则

### 1. 状态管理重构
- **统一状态总线**: 通过 `MessageBus` 统一管理所有状态更新
- **实时推送机制**: 使用事件驱动模式替代轮询
- **状态持久化**: 状态变化可追踪、可回放

### 2. 服务化架构
- **LLMService**: 独立的LLM服务，支持真正的streaming
- **StatusService**: 专门的状态管理服务
- **CrawlerService**: 解耦的爬虫服务

### 3. 响应式UI
- **组件化设计**: 可复用的UI组件
- **实时更新**: 基于事件的UI更新机制
- **错误边界**: 完善的错误处理和用户反馈

3. **LLM Streaming**: 真正的实时streaming显示

# LLM Tools 系统架构设计

## 1. 系统概述

### 1.1 系统目标
- 封装各类工具接口供大模型调用
- 提供可扩展的工具服务框架
- 支持异步处理和数据采集
- 确保系统可维护性和可扩展性

### 1.2 技术选型
- 后端框架：FastAPI
- 数据库：SQLite
- 数据验证：Pydantic
- 异步支持：asyncio
- 包管理：uv
- 测试框架：pytest

## 2. 系统架构

### 2.1 整体架构
```
┌─────────────────┐
│     API 层      │ 处理 HTTP 请求，参数验证
├─────────────────┤
│    服务层       │ 业务逻辑处理
├─────────────────┤
│    数据层       │ 数据存储和访问
└─────────────────┘
```

### 2.2 目录结构
```
llm_tools/
├── src/llm_tools_v1/     # 源代码目录
│   ├── api/             # API 层
│   ├── core/            # 核心模块
│   ├── db/              # 数据库模块
│   ├── services/        # 服务层
│   └── utils/           # 工具函数
├── docs/                # 文档目录
├── scripts/             # 脚本目录
├── tests/              # 测试目录
└── data/               # 数据目录
```

## 3. 模块划分

### 3.1 API 层 (`api/`)
- 职责：
  - 处理 HTTP 请求
  - 参数验证
  - 错误处理
  - 响应格式化
- 主要模块：
  - `deps.py`: 依赖注入
  - `errors.py`: 错误处理
  - `v1/`: API 版本 1
    - `endpoints/`: API 端点
    - `router.py`: 路由注册

### 3.2 核心模块 (`core/`)
- 职责：
  - 配置管理
  - 日志管理
  - 安全相关
- 主要模块：
  - `config.py`: 配置管理
  - `logging.py`: 日志管理
  - `security.py`: 安全相关

### 3.3 数据库模块 (`db/`)
- 职责：
  - 数据库连接管理
  - 数据模型定义
  - 数据访问层
- 主要模块：
  - `base.py`: 数据库基类
  - `session.py`: 会话管理
  - `models/`: 数据模型
    - `base.py`: 模型基类
    - `schemas.py`: 具体模型

### 3.4 服务层 (`services/`)
- 职责：
  - 业务逻辑处理
  - 工具服务实现
  - 爬虫服务实现
- 主要模块：
  - `base.py`: 服务基类
  - `crawler/`: 爬虫服务
  - `tools/`: 工具服务

### 3.5 工具函数 (`utils/`)
- 职责：
  - 通用工具函数
  - 辅助功能
- 主要模块：
  - `datetime.py`: 时间处理
  - `text.py`: 文本处理

## 4. 数据流设计

### 4.1 请求处理流程
1. 接收 HTTP 请求
2. 参数验证
3. 业务逻辑处理
4. 数据访问
5. 响应格式化

### 4.2 数据存储
- 数据库：SQLite
- 文件存储：
  - 日志文件：`data/logs/`
  - 缓存文件：`data/cache/`
  - 数据库文件：`data/db/`

## 5. 接口设计

### 5.1 API 规范
- 版本控制：URL 路径包含版本号
- 响应格式：
  ```json
  {
    "code": 200,
    "data": {},
    "msg": "success"
  }
  ```
- 错误处理：统一的错误响应格式

### 5.2 主要接口
- 工具接口：`/api/v1/tools/`
- 爬虫接口：`/api/v1/crawler/`
- 数据接口：`/api/v1/data/`

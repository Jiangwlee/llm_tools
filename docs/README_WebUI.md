# 南方电网招投标数据查询系统 Web UI

## 📖 简介

这是一个基于 Streamlit 开发的南方电网招投标数据查询系统的 Web 用户界面。通过图形化界面，用户可以轻松地下载和查询南方电网招投标数据，无需使用命令行工具。

## 🎯 功能特性

### 🔍 数据下载
- 从南方电网招投标网站自动爬取招投标公告
- 支持按甲方单位名称进行关键字搜索
- 支持投标报价和投标费率两种类型的公告
- 自动提取和分析中标价格信息
- 支持设置爬取页数限制和日期范围

### 💰 价格查询
- 查询已下载的招投标成交价格数据
- 生成详细的价格对比分析报告
- 支持数据可视化展示（柱状图、统计指标）
- 提供 CSV 格式数据导出功能

### 📊 数据分析
- 平均中标价格和最高限价统计
- 节约率计算和展示
- 项目数量和甲方数量统计
- 价格对比可视化图表

## 🛠️ 安装依赖

在运行 Web UI 之前，请确保安装了以下依赖包：

```bash
# 安装基础依赖
pip install streamlit pandas

# 安装项目依赖（如果尚未安装）
pip install playwright beautifulsoup4 openai mysql-connector-python
```

## 🚀 启动方式

### 方式一：使用启动脚本（推荐）

```bash
python run_bidding_ui.py
```

### 方式二：直接使用 Streamlit

```bash
streamlit run src/llm_tools/web_ui/bidding_csg_ui.py
```

启动后，在浏览器中访问：http://localhost:8501

## 📋 使用说明

### 1. 数据下载

1. 在侧边栏选择"数据下载"功能
2. 输入搜索关键字（例如：汕头供电局）
3. 选择公告类型：
   - 全部类型：下载所有类型的公告
   - 投标报价：只下载投标报价类型的公告
   - 投标费率：只下载投标费率类型的公告
4. 设置最大爬取页数（建议不超过50页）
5. 可选择设置结束日期，系统会停止爬取该日期之前的数据
6. 点击"🚀 开始下载数据"按钮开始下载

### 2. 价格查询

1. 在侧边栏选择"价格查询"功能
2. 输入查询关键字（与下载时使用的关键字相同）
3. 选择查询类型（投标报价 或 投标费率）
4. 点击"🔍 查询价格"按钮开始查询
5. 查看查询结果和数据分析
6. 可下载 CSV 格式的结果文件

### 3. 系统说明

- 查看详细的功能说明和使用指南
- 检查系统状态（数据库连接、依赖包状态）
- 了解技术特性和注意事项

## 🔧 系统配置

### 数据库配置

确保在 `src/llm_tools/connector.py` 中正确配置了数据库连接信息：

```python
def getConnection():
    return mysql.connector.connect(
        host='your_host',
        user='your_username',
        password='your_password',
        database='llm_tools'
    )
```

### 大模型配置

确保在相关配置文件中设置了 OpenAI API 密钥或其他大模型服务的配置。

## ⚠️ 注意事项

1. **首次使用**：请先执行数据下载，再进行价格查询
2. **网络环境**：爬取数据需要良好的网络环境
3. **爬取频率**：建议合理设置爬取页数，避免对目标网站造成过大压力
4. **数据时效性**：下载的数据会保存到数据库中，避免重复爬取
5. **系统资源**：爬取过程会启动浏览器实例，请确保系统有足够的内存

## 🐛 故障排除

### 常见问题

1. **Streamlit 未安装**
   ```bash
   pip install streamlit
   ```

2. **数据库连接失败**
   - 检查数据库服务是否运行
   - 验证连接参数是否正确
   - 确认数据库表是否已创建

3. **依赖包缺失**
   ```bash
   pip install playwright beautifulsoup4 openai pandas mysql-connector-python
   ```

4. **Playwright 浏览器未安装**
   ```bash
   playwright install chromium
   ```

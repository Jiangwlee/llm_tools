## 📋 重构原则参考

### 简单重构（直接执行）
- 变量/函数/类重命名
- 代码格式化和风格统一
- 简单代码合并或提取（≤10行）
- 移除未使用的导入或变量
- 常量提取和魔法数字消除

### 复杂重构（需要规划）
- 函数/类拆分或合并
- 架构层次调整
- 设计模式引入或重构
- 数据结构变更
- 接口签名修改
- 跨文件逻辑重组

## 🎯 使用指南

### 查找案例
1. 根据问题类型在分类中查找
2. 使用关键词搜索相关案例

# 招标公告爬虫 - 第一阶段完成

## 🎯 第一阶段目标

本阶段专注于实现两个核心功能：
1. **数据下载**：编写爬虫将网页内容下载成本地 HTML 文件，避免重复爬取
2. **配置UI**：提供一个表单式的配置页，设置爬虫参数、输出目录

## ✅ 已完成功能

### 1. 核心架构设计

```
src/biddingcsg/
├── models/
│   └── config.py          # 配置数据模型
├── services/
│   ├── storage.py         # 本地存储服务
│   └── crawler.py         # 爬虫服务
├── ui/
│   ├── components/
│   │   └── log_viewer.py  # 日志查看器组件
│   ├── pages/
│   │   └── crawler_config.py  # 爬虫配置页面
│   └── app.py            # 应用入口
├── __init__.py           # 包初始化
└── ...
```

### 2. 数据模型

- **`CrawlerConfig`**: 爬虫配置参数
  - 搜索关键词、最大页数、公告类型
  - 最早日期、输出目录
  - 请求间隔、去重设置、浏览器配置

- **`CrawlResult`**: 爬取结果数据
  - URL、标题、内容、日期
  - 公告类型、公司、项目名称
  - 文件路径信息

- **`CrawlSession`**: 爬取会话管理
  - 会话ID、配置信息、时间戳
  - 状态跟踪、结果统计

### 3. 存储服务 (`LocalStorageService`)

- **目录结构管理**: 按日期分目录保存HTML文件
- **去重机制**: URL哈希检查，避免重复爬取
- **元数据管理**: JSON格式保存文件元信息
- **会话持久化**: 爬取历史记录管理
- **存储统计**: 文件数量、大小、最新日期统计

### 4. 爬虫服务 (`BiddingCrawlerService`)

- **基于Playwright**: 处理JavaScript渲染页面
- **完整流程**: 搜索 → 翻页 → 解析 → 详情获取 → 本地保存
- **智能翻页**: 自动检测下一页按钮状态
- **错误处理**: 网络超时、页面加载失败处理
- **实时回调**: 支持进度和日志回调

### 5. UI界面

#### 配置表单
- **搜索参数**: 关键词、最大页数、公告类型、最早日期
- **输出设置**: 可自定义输出目录
- **高级设置**: 请求间隔、去重、无头模式、超时配置

#### 实时日志
- **多级日志**: INFO、WARNING、ERROR、SUCCESS
- **自动滚动**: 实时显示最新日志
- **日志导出**: 支持下载日志文件
- **清空功能**: 一键清除历史日志

#### 进度显示
- **进度条**: 可视化显示爬取进度
- **统计信息**: 当前页数/总页数、已爬取记录数
- **状态跟踪**: 运行中、已完成、失败状态

### 6. 文件存储策略

```
output/bidding_data/
├── raw_html/
│   └── 2025-01-15/
│       ├── bidding_csg_cn_20250115_143052_abc12345_项目名称.html
│       └── ...
├── metadata/
│   ├── crawl_records.json     # 爬取记录
│   ├── sessions.json          # 会话历史
│   └── *.metadata.json        # 元数据文件
└── logs/
    └── crawler_logs_*.txt      # 导出的日志文件
```

## 🚀 使用方法

### 1. 环境准备

```bash
# 安装依赖
pip install streamlit playwright beautifulsoup4

# 安装浏览器
playwright install chromium
```

### 2. 运行测试

```bash
# 运行功能测试
python test_crawler.py
```

### 3. 启动应用

```bash
# 启动Web应用
python run_crawler.py

# 或者直接运行Streamlit
streamlit run src/biddingcsg/ui/app.py
```

### 4. 访问界面

在浏览器中打开 `http://localhost:8501`

## 🔧 配置参数说明

| 参数 | 说明 | 默认值 | 备注 |
|------|------|--------|------|
| 搜索关键词 | 要搜索的关键词 | 无 | 必填，支持公司名称、项目名称等 |
| 最大爬取页数 | 限制爬取页数 | 10 | 1-1000，避免过度爬取 |
| 公告类型 | 公告分类 | "服务" | 服务/招标公告/公示公告 |
| 最早日期 | 日期限制 | 无 | YYYY-MM-DD格式，留空不限制 |
| 输出目录 | 保存路径 | "./output/bidding_data" | 可自定义路径 |
| 请求间隔 | 请求延迟 | 2.0秒 | 0.5-10秒，防反爬虫 |
| 启用去重 | URL去重 | 是 | 跳过已爬取的URL |
| 无头模式 | 后台运行 | 是 | 推荐开启，减少资源占用 |
| 页面超时 | 加载超时 | 30秒 | 10-120秒 |

## 📊 技术特性

- **智能去重**: 基于URL的重复检测机制
- **断点续传**: 支持停止后继续爬取（基于已保存的URL记录）
- **实时监控**: Web界面实时显示爬取进度和日志
- **文件管理**: 结构化的本地文件存储，易于管理
- **错误恢复**: 单页面失败不影响整体爬取进程
- **数据完整性**: 保存原始HTML和结构化元数据

## ⚠️ 注意事项

1. **遵守robots.txt规则**，合理设置请求间隔
2. **网络环境**：确保能正常访问南方电网招标网站
3. **磁盘空间**：大量爬取时注意磁盘容量
4. **浏览器依赖**：需要Chromium浏览器支持
5. **内存使用**：长时间运行建议监控内存使用情况

## 🐛 已知限制

1. **并发限制**: 当前为单线程爬取，未来可考虑多线程优化
2. **网站变更**: 页面结构变化可能需要调整解析逻辑
3. **大数据量**: 超大量数据时建议分批处理
4. **实时性**: UI日志更新基于回调，可能有轻微延迟
